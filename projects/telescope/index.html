開始操作 →Start the simulator · opens on this page

桌上型杜布森反射望遠鏡放在校園走廊，對面大樓掛著「中壢高中」的招牌。照操作面板的六個步驟：取下鏡筒蓋、裝目鏡、找招牌、調焦、觀察倒像、校正尋星鏡。做完一步會自動檢核，再帶到下一步。iPad 與電腦都可以用。

關於

學生第一次操作望遠鏡，常卡在幾個固定的地方：忘了拿鏡筒蓋、目鏡沒鎖緊、找不到目標、不知道為什麼影像是倒的、尋星鏡和主鏡看的不是同一個地方。這些在實際器材前要一個一個排隊問老師，上課時間大多花在等待。

這個作品把學習單〈望遠鏡怎麼用？〉的任務一做成網頁上的 3D 模擬。每個動作都有對應的變化：鏡筒蓋沒拿掉，主鏡視野就是黑的；調焦鈕一轉，字由模糊變清楚。兩個圓形視野都呈現上下左右顛倒的影像。鏡筒轉向太陽時，畫面會立刻遮蔽並跳出警告。

學生在課前或課後先練熟順序，實作時間就能留給真正的觀測。

About

Students using a telescope for the first time get stuck in the same places: the dust cap is still on, the eyepiece is not locked, the target cannot be found, the image is upside down, and the finder does not point where the main tube does. At the real instrument each of these becomes a queue for the teacher.

This work turns the first task of the worksheet “How to Use a Telescope” into a 3D simulation in the browser. Every action has a visible result: with the cap on, the eyepiece view is black; turning the focuser brings the letters into focus. Both round views show the image turned upside down and left to right, as a real telescope does. If the tube swings toward the sun, both views are covered and a warning appears.

Students practise the sequence before or after class, so lesson time is left for real observing.

六個步驟

  1. 取下鏡筒蓋。
  2. 插入 20 mm 目鏡，輕輕鎖緊固定螺絲。
  3. 推動鏡筒，讓主鏡對準「中壢高中」。
  4. 轉調焦鈕，讓字變清楚。
  5. 觀察倒像：字是上下左右都顛倒的。為什麼？
  6. 只轉尋星鏡的螺絲，讓十字線對到主鏡看到的同一處。

Six steps

  1. Take off the dust cap.
  2. Insert the 20 mm eyepiece and lock it gently.
  3. Push the tube until the main view finds the sign.
  4. Turn the focuser until the letters are sharp.
  5. Notice the image is upside down and reversed.
  6. Turn only the finder’s screws until its crosshair meets the same point.

為什麼是顛倒的 · How it works

把望遠鏡變透明、拆開，再讓光走一次，就看得出像是在哪裡顛倒的。Make the telescope transparent, take it apart, then follow the light to see where the image turns over.

延伸 · 焦點 · Focus

紙放在焦點上，像最清楚；往前或往後都會糊。轉調焦鈕，就是在把目鏡移到這個位置。

示意圖：主鏡口徑 130 mm、焦距 650 mm；尋星鏡 6×30。光束的夾角與鏡面弧度畫得比實際明顯，底座為示意。實際的像還會隨觀察者站的位置轉動，這裡統一畫成轉 180°。

設計

畫面只有兩個部分：佔滿螢幕的 3D 望遠鏡，和一個可以整個收合的操作面板。面板依序顯示現在這一步、要用的工具和兩個觀測視野；面板收合或展開時，望遠鏡的位置不會改變。模型上平常只標出這一步要動的零件。

Design

The screen has two parts: the telescope in 3D, filling the screen, and one control panel that folds away completely. The panel shows the current step, the tool it needs and the two views. Opening or closing it never moves the telescope. Only the part used in the current step is labelled on the model.
